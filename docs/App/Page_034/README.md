The content that used to sit here described the **D-465 stacked-cards** layout —
a "اختر الجلسة" picker, a "generated by AI" banner, three cards shown at once, and
a "النص الكامل / مشاركة / حفظ" action row. None of that is the screen any more:
the D-612 rework replaced it with a session card, up to two video players, a
three-tab content card (أبرز النقاط · التوصيات · المتحدثون) and an expandable
full-text card. The banner and the action row are gone, and `generatedByAi` is
decoded but rendered nowhere.

One claim in the old text was wrong even about its own layout, and is corrected in
the new file: "with **no** id it shows a neutral 'open a summary from a session'
state and never fetches" contradicts the sentence two paragraphs below it. The
screen has always auto-selected the first programme session when no id is passed;
`l10n.aiSummaryOpenFromSession` exists but no branch renders it.

Route, endpoint, providers, wire contract, states, actions and the open findings
are all recorded in the new file.
