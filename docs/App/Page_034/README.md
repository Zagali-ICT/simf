## API (authoritative contract)
Reuses the shipped public summary read (no new API):
- `GET /api/v1/app/programme/sessions/{id}/summary` → `ApiResult<PublicSessionSummary>`
  — `keyPoints`/`keyPointsArabic`, `recommendations`/`recommendationsArabic`,
  `speakers`/`speakersArabic`, `fullText`/`fullTextArabic`, `generatedByAi` (bool),
  `publishedAt` (string). `AllowAnonymous`.

`keyPoints` / `keyPointsArabic` are **newline-delimited** — one bullet per
non-empty line (`SessionSummary.keyPointsLines(isArabic)`). A 404
(`SessionSummaryNotFound`) means the session has no published summary yet.

## Behaviour
The screen takes an **optional** `sessionId` (wired from the `?sessionId=` query
parameter — it is opened from a session). With **no** id it shows a neutral
"open a summary from a session" state and never fetches. With an id it reads the
published summary and renders the present sections:

- the **"اختر الجلسة"** picker (reuses the programme list) + a **"generated by AI"**
  banner when `generatedByAi` is true;
- **stacked cards** (Figma `1078:14952` — no tabs): **أبرز النقاط** + **التوصيات**
  as bullet cards, **المتحدثون** as a "·"-joined line, all shown at once;
- the **النص الكامل / مشاركة / حفظ** action row (full text opens a sheet).

With **no** id the first programme session is auto-selected. States: loading ·
not-found (404 → "no published summary yet", picker still shown) · error + Retry.
Bilingual (AR/EN by `l10n.isArabic`, RTL-safe).
