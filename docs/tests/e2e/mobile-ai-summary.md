## Scenarios

```gherkin
Feature: AI session summary (Figma 1078:14952)
  As a guest
  I want a chosen session's AI summary as stacked cards
  So that I can read the key points, recommendations and speakers together

Scenario: The screen renders the picker, the AI banner and the stacked cards
  Given the programme list returns sessions and session "s1" has a published summary
  When /ai-summary?sessionId=s1 opens
  Then the "Choose the session" picker and the "Auto-generated summary" banner are shown
  And the three headings (Key points / Recommendations / Speakers) each show as a card
  And all three sections' content is visible at once (no tab gating)
  And the speakers show as one "·"-joined line
  And the action row (Full text / Share / Save) is shown

Scenario: No sessionId auto-selects the first session
  Given /ai-summary opens with no sessionId and the programme has sessions
  Then the first session is selected and its summary is fetched (banner shown)

Scenario: A 404 shows the no-published-summary state
  Given the selected session has no published summary
  Then "No published summary yet." is shown and the picker still renders

Scenario: A non-404 failure offers retry
  Given the summary read fails with 500
  Then "Could not load the summary." + a Retry button are shown
  When the user taps Retry
  Then the summary is re-fetched
```

**Evidence:** screen tests (4) + model test (bilingual fallback + line splitting).
