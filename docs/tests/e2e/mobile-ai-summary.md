## Scenarios

### E2E-MOB034-001 — Open a session summary

```gherkin
Feature: AI session summary
  As a guest (signed out)
  I want a session's AI-generated summary
  So that I can catch up without watching the full session

Scenario: Opening with a sessionId renders the summary
  Given a session with a published summary
  When the app calls GET /api/v1/app/programme/sessions/{id}/summary
  Then it returns 200 with the summary
  And a "Generated by AI" banner is shown when generatedByAi is true
  And the Key points block is rendered as one bullet per non-empty line
  And Recommendations, Speakers and Full text are shown when non-empty
```

**Evidence:** screen test `renders the summary sections + the AI banner`.

### E2E-MOB034-002 / 003 — No / blank id empty state

```gherkin
Scenario: No sessionId shows the open-from-session state and never fetches
  Given the screen is opened with no sessionId query parameter
  Then it shows the "Open a session summary from a session." state
  And no summary read is performed

Scenario: A blank sessionId is treated as no id
  Given the screen is opened with sessionId = "   "
  Then it shows the same empty state and performs no read
```

**Evidence:** screen tests `no sessionId shows the open-from-session empty state — no fetch`,
`a blank sessionId is treated as no id`.

### E2E-MOB034-004 / 005 — Not-found / error+retry

```gherkin
Scenario: A 404 shows the no-summary state
  Given GET .../summary returns 404 (SessionSummaryNotFound)
  Then the screen shows "No published summary yet."

Scenario: A failed read offers a retry
  Given the summary read fails with a non-404 error
  Then an error + Retry are shown, and Retry re-runs the read
```

**Evidence:** screen tests `a 404 shows the no-published-summary state`,
`a non-404 failure shows error + retry, which re-fetches`.

### E2E-MOB034-006 — Key-point split + language fallback

```gherkin
Scenario: Newline-delimited key points become bullets
  Given keyPoints = "Alpha\n\n  Beta  \nGamma\n"
  Then keyPointsLines() yields ["Alpha", "Beta", "Gamma"]

Scenario: A missing Arabic block falls back to English
  Given keyPointsArabic is empty
  When the active language is Arabic
  Then the English key points are shown
```

**Evidence:** model tests `keyPointsLines`.
