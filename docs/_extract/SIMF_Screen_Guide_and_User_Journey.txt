1. About this document
This guide walks through every screen of the SIMF 2026 mobile application proposal. For each screen you will find:
What the screen is for, its purpose in plain language.
The key elements visible on the screen.
The links and buttons on the screen, and where each one takes the user.
Where the screen sits inside the overall user journey.
At the end of the document, a connections map shows how screens link to each other so reviewers can confirm the flow is complete and consistent.
Note The mockup is an interactive structural proposal, not a finished visual design. Design, colours, illustrations and motion will be refined in the design phase.
2. The bottom navigation system
Every main screen carries the same five-slot bottom navigation bar. The slots are fixed in this order (right to left, since the app is RTL Arabic-primary):
الرئيسية · Home: returns to the dashboard (Screen 13)
الأجندة · Agenda: opens the schedule (Screen 16)
Badge FAB (centre, brass): opens the entry badge &amp; QR (Screen 32)
الخريطة · Map: opens the 3D venue map (Screen 15)
التغطية الإعلامية · Media: opens the news + gallery + partners tabs (Screens 29–31)
The user’s profile and the notifications bell appear in the top bar of the dashboard, not in the bottom nav. The bottom nav stays consistent on every authenticated screen so the user can always reach the main areas in one tap.
3. The five main user journeys
Journey A — First-time visitor sign-up
A new attendee opens the app, picks a role, and finishes registration before the event.
Splash (1) → Onboarding (2) → Sign-up form (4) → Personal details + role pick (5) → Email OTP verification (6) → Visitor row pick OR Sponsor details (7 or 8) → Terms &amp; conditions (9) → Registration confirmed (10) → Registration status (11).
Journey B — Returning attendee login
Splash (1) → Login (3) → Home dashboard (13). From here, every other feature is one tap away.
Journey C — Browsing as a guest (no account)
Splash (1) → Guest mode (12). The guest can open the agenda, speakers list, map and media gallery, plus the FAQ and Visit Saudi content. Personal features (smart badge, meeting requests, notifications) are locked behind sign-in.
Journey D — Conference-day flow (during the event)
Home (13) → Live broadcast banner → Live screen (25). From inside the live view the user can:
Send a question to the speaker or host (Screen 26).
Request an interview with a speaker (Screen 27).
See audience comments with answer status and likes (Screen 28).
In parallel: open the QR badge (32) for entry, scan another attendee's QR to save their contact, and react to notifications (33).
Journey E — Agenda planning
Home (13) → Agenda (16) → tap a session → Session detail (17). From the detail screen the user can add the session to their device calendar, set a reminder, and view their assigned seat → My Seat map (18). The session also appears in My Area (14) under “today’s schedule”.
