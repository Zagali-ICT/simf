===== ppt/slides/slide7.xml =====

SECURITY
Defense-in-depth at every layer
Token Headers
App Key + Device Type + Language + JWT on every request.
Auth &amp; Refresh
JWT expires in 30 minutes; refresh tokens rotate; sessions valid 30 days.
Admin MFA
Google Authenticator TOTP required for every administrative login.
Anti-Forgery
SFC tokens on every state-changing request   CSRF blocked by design.
Rate Limiting
Per-IP, per-user, per-endpoint   brute force throttled at the edge.
RBAC
Role-based access on every endpoint. No endpoint is implicitly open.

Reads Serilog audit streams, surfaces anomalies, and powers natural-language filtering for compliance officers.
Smart Search
Find audit events by plain-language queries   no SQL or filters needed.
Intelligent Filtering

Anomaly Detection

===== ppt/slides/slide12.xml =====

QUALITY STANDARDS
Engineering rules we never break
Zero warnings
Warnings are treated as errors. The build is clean   always.
Root-cause fixes
No guesswork. Every issue is traced to its source before it's patched.
Peer code review
Every pull request is reviewed by at least one other engineer before merge.

Freeze governance

===== ppt/slides/slide14.xml =====

TESTING
Three independent test layers
Unit Tests
PER METHOD
Every branch, every edge case, every error path. Fast and isolated   they run on every commit.
Integration Tests
PER API ENDPOINT
Happy path plus every error code an endpoint can return. Catches contract drift early.
End-to-End Tests
PER USER SCENARIO
Full flow including failure recovery. Proves the system works the way the customer will use it.
No feature ships unless all three layers pass   and stay passing.
